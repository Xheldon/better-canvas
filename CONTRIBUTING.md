# Contributing

Better Canvas is a React/TypeScript project for read-only Canvas previews and AI edits over MCP.

Keep changes focused, preserve original Canvas geometry and unknown JSON fields, and avoid adding browser editing actions or a separate AI chat. See CLAUDE.md for the architecture and invariants.

Use generic examples only. Do not submit private vaults, local logs or credentials.

Run the checks in docs/testing.md. Include manual UI evidence for interaction changes and state whether host-message testing used a simulated or real host.
